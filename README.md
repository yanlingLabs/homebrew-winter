# Norma Homebrew Tap

Install [Norma](https://github.com/yanlingLabs/norma):

```sh
brew tap yanlingLabs/norma
brew install --cask norma
```

Or in one line:

```sh
brew install --cask yanlingLabs/norma/norma
```

Norma keeps itself up to date via Sparkle, so `auto_updates true` is set on the cask.
